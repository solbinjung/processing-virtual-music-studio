# 🎹 인터랙티브 핸드 트래킹 악기 연주 (Interactive Hand Tracking Instrument)

> **개발 기간:** 2025.11 ~ 2025.12 (약 1개월)  
> **개발 형태:** 2인 팀 프로젝트  
> **사용 기술:** Processing, Arduino, C++

---

## 📝 프로젝트 소개 (Description)
웹캠을 통해 특정 색상(손)을 실시간으로 인식하여 화면 속 가상 악기(피아노, 드럼, 기타)를 연주하는 멀티미디어 인터랙션 프로그램입니다. 아두이노 조이스틱 센서와의 시리얼 통신을 연동하여 인터페이스 내에서 악기 모드를 동적으로 전환할 수 있도록 구현했습니다.

---

## 🛠️ 담당 역할 및 주요 구현 (My Role & Key Implementation)

2인 팀 프로젝트에서 **컴퓨터 비전 기반 입력 인터페이스(컬러 트래킹)**와 핵심 플레이 콘텐츠인 **가상 피아노 시스템** 설계를 전담하여 개발했습니다.

### 1. 순수 픽셀 연산 기반 실시간 컬러 트래킹 (Computer Vision)
외부 컴퓨터 비전 라이브러리(OpenCV 등)에 의존하지 않고, 웹캠 프레임의 1차원 픽셀 배열 데이터에 직접 접근하는 독자적인 트래킹 알고리즘을 설계했습니다.

* **RGB 유클리드 거리 판정:** 픽셀 배열(`video.pixels`)을 전수 순회하며 사용자가 지정한 타겟 색상(`trackColor`)과 현재 픽셀 RGB 값 간의 3차원 유클리드 거리를 계산하여 마커를 검출합니다.
* **좌표 안정화 (Jittering 억제):** 카메라 센서 노이즈로 인한 마커 좌표의 미세한 흔들림을 제어하기 위해 선형 보간 함수(`lerp`)를 적용, 입력 반응성을 유지하면서 정밀하게 좌표 이동을 감쇄 연동시켰습니다.
* **동적 런타임 캘리브레이션:** 사용자의 환경적 한계(조명 차이 등)를 보완하기 위해 화면 클릭 시 해당 좌표의 RGB 값을 추적 색상으로 즉시 동적 바인딩하는 최적화 기능을 구현했습니다.

### 2. 가상 피아노 및 실시간 시각 효과 시스템 (Gameplay Features)
추적된 가상 좌표를 활용하여 실제 연주가 가능한 7개 흰 건반, 5개 검은 건반 인터페이스를 구현하고 최적화했습니다.

* **에지 트리거(Edge Trigger) 판정:** 가상 손 좌표가 건반 영역에 머무를 때 사운드 파일이 무한 중복 재생되는 '다단 히트' 버그를 해결하기 위해 건반별 불리언 상태 플래그를 도입, 진입 시점에 단 1회만 사운드가 트리거되도록 예외 처리를 구현했습니다.
* **객체 지향 기반 파티클 시스템:** 건반이 입력되는 순간 가상의 연주 좌표에 매칭되는 마커 색상의 잉크 파티클(`PianoParticle`)을 동적으로 생성하는 이펙트 구조를 개발했습니다.
* **메모리 최적화 생명 주기 제어:** 각 파티클 객체에 업워드 가속도 벡터를 부여하고 매 프레임 수명치(`lifespan`)를 감쇄시켜 알파 채널(투명도)과 유기적으로 연동한 후, 소멸 시점에 리스트에서 안전하게 제거(`remove`)하여 가비지 축적을 방지했습니다.
