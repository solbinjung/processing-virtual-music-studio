# 🎹 인터랙티브 핸드 트래킹 악기 연주 (Interactive Hand Tracking Instrument)

> **개발 기간:** 2025.11.25 ~ 2025.12.12 (2주)  
> **개발 형태:** 2인 팀 프로젝트  
> **사용 기술:** Processing, Arduino(C++)<br>
> **시연 영상:** <https://youtu.be/aO1MyjeBnPg>

웹캠을 통해 특정 색상(사용자의 손)을 실시간으로 인식하여 화면 속 가상 악기(피아노, 드럼, 기타)를 연주하는 멀티미디어 인터랙션 프로그램입니다. 아두이노 조이스틱 센서와의 시리얼 통신을 연동하여 프로그램 인터페이스 내에서 악기 모드를 동적으로 전환할 수 있도록 구현했습니다.

---

🛠️ 시스템 구성 및 하드웨어 아키텍처
* **영상 입력:** 웹캠 디바이스 (Processing Video 라이브러리 활용)
* **제어 장치:** 아두이노 우노 R3 + 조이스틱 센서 (Serial 통신을 통한 데이터 송수신)
* **출력 및 사운드:** 가상 악기 GUI 화면 시각화 + processing.sound 라이브러리를 통한 오디오 출력

## 🛠️ 핵심 구현 및 기술적 문제 해결

2인 팀 프로젝트에서 컴퓨터 비전 기반 영상 입력 시스템(컬러 트래킹)과 핵심 플레이 콘텐츠인 **가상 피아노 엔진 및 시각 효과 시스템** 개발을 전담했습니다.

### 1. 원시 픽셀(Raw Pixel) 분석을 통한 컬러 트래킹 알고리즘 구현
외부 컴퓨터 비전 라이브러리(OpenCV 등)에 의존하지 않고 웹캠 프레임의 1차원 픽셀 데이터 배열(`video.pixels`)에 직접 접근하여 실시간 마커 추적 알고리즘을 설계했습니다.

* **3차원 RGB 유클리드 거리 판정:** 픽셀 배열을 전수 순회하며 'dist()' 함수를 통해 사용자가 지정한 타겟 색상(`trackColor1`, `trackColor2`)과 현재 픽셀의 RGB 값 간의 거리를 계산하고 설정한 임계값(`threshold = 25`) 미만인 유효 픽셀만 필터링했습니다.

* **거울 모드(Mirroring) 및 무게 중심 좌표 추출:** 사용자가 화면을 보며 직관적으로 조작할 수 있도록 좌우 반전 플립 연산(`camW - avgX`)을 적용했으며 필터링된 유효 픽셀들의 평균값을 계산하여 노이즈에 강한 손의 무게 중심(Centroid) 좌표를 산출했습니다.

* **듀얼 컬러 확장을 통한 양손 독립 추적:** 두 가지 타겟 색상을 독립적으로 연산하는 로직을 구축하여 가상 악기 연주에 필수적인 양손 동시 입력 시스템을 구현했습니다.

* **선형 보간(Lerp) 기반의 좌표 떨림(Jittering) 방지:** 웹캠 센서의 특성상 입력 좌표가 미세하게 떨리는 현상을 제어하기 위해 `lerp()` 함수를 적용하여, `0.1`의 보간 계수로 입력 반응성을 유지하면서 부드러운 연주감을 확보했습니다.

* **마우스 좌/우 클릭을 통한 실시간 색상 캘리브레이션:** 조명 변화 등 외부 환경에 따른 인식률 저하를 방지하기 위해 런타임 환경에서 마우스 왼쪽 클릭 시 `trackColor1`, 오른쪽 클릭 시 `trackColor2`로 추적 대상을 즉시 업데이트하는 보정 기능을 구현했습니다.

### 2. 가상 피아노 엔진 설계 및 메모리 최적화
추적된 양손의 보간 좌표(`lerpX`, `lerpY`)를 활용하여 실제 피아노 건반 구조(흰 건반 7개, 검은 건반 5개)와 매핑되는 연주 엔진을 개발했습니다.

* **2차원 경계 영역 충돌 감지:** 입력 좌표가 흰 건반 및 검은 건반의 배치 영역(Y축 `keyStartY = 260` 기준 및 건반별 Width/Height 범위) 내부에 포함되었는지를 실시간으로 체크하는 충돌 판정 알고리즘을 구현했습니다.

* **상태 플래그(Flag) 변수를 활용한 사운드 중복 재생 방지:** 손 좌표가 건반 영역 내에 머무를 때 매 프레임마다 사운드가 중첩 호출되어 오디오가 중복되는 현상을 해결하기 위해 건반별 Boolean 배열(`isWhiteKeyPressed`, `isBlackKeyPressed`)을 도입했습니다. 이를 통해 '누르지 않은 상태에서 처음 진입한 시점'에만 단 1회 사운드가 트리거되도록 제어했습니다.

* **역방향 루프(Reverse Loop)를 통한 메모리 누수 방지:** 건반 입력 순간 동적으로 잉크 효과를 내는 `PianoParticle` 객체를 생성하고 이를 `ArrayList`로 관리했습니다. 매 프레임 수명치(`lifespan`)가 다해 소멸하는 객체를 지울 때 인덱스 오프셋 오류를 방지하기 위해 **역방향 포문**을 순회하도록 설계하여 가비지(Garbage) 축적으로 인한 메모리 누수를 완전히 차단했습니다.

for (int i = pianoParticles.size() - 1; i >= 0; i--) {
    PianoParticle p = pianoParticles.get(i);

  }
